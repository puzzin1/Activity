## ✨ Ключевые возможности

### 🎯 Основной функционал
| Возможность | Описание |
|------------|----------|
| **🖱️ Движение мыши** | Плавные, естественные движения с ограниченным диапазоном |
| **⌨️ Нажатие клавиш** | Прокрутка стрелками, безопасные клавиши, Ctrl+Tab |
| **📅 Умное расписание** | Автоматическая генерация рабочего дня с перерывами |
| **🎉 Специальная пятница** | Короткий рабочий день с ранним завершением |
| **🌙 Внерабочий режим** | Всплески активности до/после работы |
| **🍽️ Действия после обеда** | Автоматический ввод последовательностей клавиш |

### 🔐 Безопасность и контроль
| Функция | Защита |
|---------|---------|
| **🛡️ Минимальная задержка** | 60 секунд ожидания после любой активности пользователя |
| **🚫 Прерывание действий** | Немедленное прерывание при обнаружении активности пользователя |
| **🚪 Умное завершение** | Выход при активности после рабочего дня |
| **🔒 Безопасный выход** | Простое завершение по Ctrl+C без блокировки |
| **📝 Детальное логирование** | Полная запись всех действий в лог-файл |

## 🚀 Быстрый старт

### 1️⃣ Установка Python

Программа требует **Python 3.8** или выше. Если Python ещё не установлен:

#### Windows

1. Скачайте установщик с официального сайта: **[python.org/downloads](https://www.python.org/downloads/)**
2. Запустите скачанный файл
3. **Обязательно** отметьте галочку **"Add Python to PATH"** (Add python.exe to PATH) на первом экране установщика
4. Нажмите **"Install Now"** и дождитесь завершения
5. Проверьте установку — откройте командную строку (`Win+R` → `cmd`) и введите:
   ```bash
   python --version
   ```
   Должно отобразиться что-то вроде: `Python 3.12.x`

#### macOS

1. Скачайте установщик с **[python.org/downloads](https://www.python.org/downloads/)** или установите через Homebrew:
   ```bash
   brew install python3
   ```
2. Проверьте установку:
   ```bash
   python3 --version
   ```

#### Linux

Python обычно уже установлен. Проверьте:
```bash
python3 --version
```
Если нет — установите через пакетный менеджер:
```bash
# Ubuntu / Debian
sudo apt install python3 python3-pip

# Fedora
sudo dnf install python3 python3-pip

# Arch
sudo pacman -S python python-pip
```

### 2️⃣ Скачивание программы

Скачайте архив с проектом и распакуйте в удобную папку, или клонируйте через Git:
```bash
git clone <url-репозитория>
cd Activity
```

### 3️⃣ Установка зависимостей

Откройте терминал (командную строку) в папке проекта и выполните:
```bash
# Windows
pip install pynput pyyaml

# macOS / Linux
pip3 install pynput pyyaml
```

**Примечание:** Библиотека `pyyaml` требуется для работы с конфигурацией YAML. Если она не установлена, программа будет использовать настройки по умолчанию.

### 4️⃣ Запуск программы

#### Windows (самый простой способ)
```bash
# Двойной клик на файл:
activity.bat

# Или из командной строки:
python -m activity_simulator
```

#### macOS / Linux
```bash
python -m activity_simulator
```

#### После установки пакета (опционально)
```bash
# Установить в режиме разработки
pip install -e .

# Запустить через консольный скрипт
activity-simulator
```

### 🎯 Первый запуск
При первом запуске программа автоматически:
1. **📄 Проверяет** наличие `config.yaml` в корневой директории (создает при отсутствии с настройками по умолчанию)
2. **📅 Создает** ежедневный файл конфигурации `activity_config_YYYYMMDD.json` с расписанием на день
3. **ℹ️ Показывает** информацию о настройках и расписании
4. **▶️ Начинает** работу в соответствующем режиме

### ⏸️ Остановка программы
Нажмите **`Ctrl+C`** в консоли — программа безопасно завершится.

## ⚙️ Конфигурация

### 📄 Файлы конфигурации
Программа использует два уровня конфигурации:

#### 1. **Основной файл настроек** (`config.yaml`)
- **Расположение:** Корневая директория проекта
- **Назначение:** Содержит все настройки программы с подробными комментариями
- **Редактирование:** Изменяется вручную, влияет на все последующие запуски
- **Создание:** При первом запуске с установленным PyYAML создается автоматически

#### 2. **Ежедневные файлы конфигурации** (`activity_config_YYYYMMDD.json`)
- **Назначение:** Содержат расписание на конкретный день, сгенерированное на основе `config.yaml`
- **Создание:** Автоматически при первом запуске каждого дня
- **Повторное использование:** Если файл уже существует, используется повторно

```
config.yaml (корневая директория)      →      activity_config_20260217.json
├── Все настройки программы                  ├── config:     Настройки из config.yaml
├── Подробные комментарии                   ├── schedule:   Расписание на день
└── Редактируется вручную                   └── created_at: Дата создания
```

**Примечание для разработчиков:** Исходные настройки по умолчанию определены в файле `activity_simulator/config.py` в словаре `DEFAULT_CONFIG`. Они используются как резервный вариант если YAML недоступен.

### 🎮 Основные параметры

#### Параметры симуляции
```yaml
min_idle_time: 30           # Мин. время бездействия (сек)
max_idle_time: 70           # Макс. время бездействия (сек)
min_action_interval: 3      # Мин. интервал между действиями (сек)
max_action_interval: 20     # Макс. интервал между действиями (сек)
max_mouse_range: 50         # Диапазон движения мыши (пикс)
natural_behavior: true      # Естественное поведение (плавные движения)
```

#### Веса действий
```yaml
use_mouse_move: true         # Включить движение мыши
use_keyboard: true           # Включить нажатие стрелок
use_mouse_click: true        # Включить клики мыши

action_weight_mouse_move: 3  # Вероятность движения мыши (чем больше, тем чаще)
action_weight_keyboard: 3    # Вероятность нажатия стрелок
action_weight_ctrl_tab: 1    # Вероятность Ctrl+Tab
action_weight_mouse_click: 2 # Вероятность кликов
action_weight_safe_key: 2    # Вероятность безопасной клавиши (Shift)
```

### ⏰ Расписание работы
```yaml
work_start_min: '08:45'     # Раннее начало работы
work_start_max: '09:05'     # Позднее начало работы
work_end_min: '18:00'       # Раннее окончание работы (Пн-Чт)
work_end_max: '18:20'       # Позднее окончание работы (Пн-Чт)

friday_work_end_min: '16:35' # Раннее окончание в ПЯТНИЦУ
friday_work_end_max: '16:55' # Позднее окончание в ПЯТНИЦУ

lunch_start_min: '12:00'    # Раннее начало обеда
lunch_end_max: '14:30'      # Позднее окончание обеда
lunch_duration_min: 20      # Мин. длительность обеда (мин)
lunch_duration_max: 30      # Макс. длительность обеда (мин)

total_break_min: 40         # Мин. общее время коротких перерывов (мин)
total_break_max: 80         # Макс. общее время коротких перерывов (мин)
```

**Особенности расписания:**
- 🎉 **Пятница автоматически определяется** — рабочий день заканчивается раньше (16:35-16:55)
- 📅 **Обед + короткие перерывы** — равномерное распределение в течение дня
- ⏰ **Случайное время** — в заданных пределах для естественности

#### 🍽️ Действия после обеда
```yaml
after_lunch_action: false                  # Включить ввод последовательности после обеда
after_lunch_sequence: 'AFTER_LUNCH_SEQUENCE' # Имя переменной окружения
after_lunch_delay: 5                       # Задержка после обеда перед вводом (сек)
```

**Переменная окружения:**
Для безопасности конфиденциальные данные хранятся в переменной окружения, а не в файле конфигурации.

**Установка переменной окружения:**
- Windows: `set AFTER_LUNCH_SEQUENCE=mypassword{Enter}`
- Linux/Mac: `export AFTER_LUNCH_SEQUENCE=mypassword{Enter}`

**Специальные клавиши:**
- `{Enter}` — клавиша Enter
- `{Tab}` — клавиша Tab
- `{Space}` — пробел

**Примеры значений переменной окружения:**
- `"mypassword{Enter}"` — ввод пароля и нажатие Enter
- `"login{Tab}password{Enter}"` — логин, Tab, пароль, Enter
- `"user{Tab}{Tab}pass{Enter}"` — user, дважды Tab, пароль, Enter

#### 🔒 Завершение работы
```yaml
lock_on_exit: true           # Блокировать компьютер при автоматическом завершении
shutdown_on_exit: false      # Выключить компьютер при автоматическом завершении
show_shutdown_warning: true  # Показать предупреждение перед блокировкой/выключением
shutdown_warning_time: 30    # Время показа предупреждения (сек)
```

**Примечания:**
- 🔐 **Безопасность:** При ручной остановке (`Ctrl+C`) программа просто завершается без блокировки/выключения
- ⚠️ **Предупреждение:** `shutdown_on_exit` имеет приоритет над `lock_on_exit`
- ⏰ **Таймер:** Предупреждение можно отменить в течение `shutdown_warning_time` секунд

## 🎭 Режимы работы

### 📊 Диаграмма работы программы
```
    08:45 - 09:05           Рабочее время         18:00 - 18:20 (16:35-16:55 пт)
          ↓                        ↓                        ↓
[До работы] → [РАБОЧИЙ РЕЖИМ] → [Перерывы] → [РАБОЧИЙ РЕЖИМ] → [После работы]
     ↑           ↑             ↑         ↑             ↑             ↑
 Всплески   Полная        Обед   Короткие      Полная        Всплески
активности  симуляция          перерывы        симуляция     активности
```

### 1️⃣ Рабочий режим
**Когда:** В рабочие часы (не на перерыве)

**Что делает:**
- 🖱️ **Движение мыши** — плавные движения в ограниченном диапазоне
- ⌨️ **Нажатие клавиш** — стрелки (↑↓←→) для прокрутки
- 🔄 **Ctrl+Tab** — имитация переключения вкладок
- 👆 **Клики мыши** — левая кнопка (если включено)
- ⇧ **Безопасная клавиша** — Shift (без эффекта)

### 2️⃣ Режим перерыва
**Когда:** Во время обеда или короткого перерыва

**Что делает:**
- ⏸️ **Приостановка активности** — полное отсутствие действий
- ⌨️ **После обеда** — ввод последовательности клавиш (если настроено)

**Типы перерывов:**
- **🍽️ Обед:** 20-30 минут в диапазоне 12:00-14:30
- **☕ Короткие перерывы:** 3-8 минут каждый, распределены равномерно

### 3️⃣ Внерабочий режим
**Когда:** До начала или после окончания рабочего дня

**Режимы (`afterhours_mode`):**

| Режим | Активность | Завершение |
|-------|------------|------------|
| `"disabled"` | ❌ Нет активности | ✅ Автоматическое в конце дня |
| `"before_only"` | ☀️ Только утром до работы | ✅ Автоматическое в конце дня |
| `"before_and_after"` | 🌙 Утром и вечером | ❌ Работает круглосуточно |

**Всплески активности:**
- ⏱️ **Длительность:** 30-70 секунд
- ⏲️ **Интервал:** 7-9 минут
- 🖱️ **Действия:** Только легкие (движение мыши и Shift)

## 🛡️ Защита от помех пользователю

### ⚡ Мгновенное прерывание
Программа немедленно прерывает любые действия при обнаружении активности пользователя:

```
┌─────────────────────────────────────────────┐
│  Программа: Начинает серию из 10 нажатий →  │
│  Пользователь: Нажимает клавишу             │
│  Программа: ⚡ ПРЕРЫВАЕТ серию              │
│  Программа: ⏳ Ждет 60 секунд               │
└─────────────────────────────────────────────┘
```

### 🛑 Минимальная задержка 60 секунд
После **любой** активности пользователя программа ждет минимум 60 секунд перед возобновлением действий:

| Активность пользователя | Реакция программы |
|-------------------------|-------------------|
| 🖱️ Движение мыши/тачпада | ⏳ Ожидание 60 секунд |
| 👆 Клик мыши | ⏳ Ожидание 60 секунд |
| ⌨️ Нажатие клавиши | ⏳ Ожидание 60 секунд |

### 📝 Пример в логе
```
[INFO] Обнаружено движение мыши пользователем: (1597, 901)
[WARNING] ⚠️ Серия нажатий прервана активностью пользователя (выполнено 3/10)
[DEBUG] Ожидание после активности пользователя. Осталось: 60.0 сек
```

## 🚪 Умное завершение

### 👁️ Обнаружение активности после работы
Если включено `exit_on_activity_after_work: true`:

**Сценарий:**
```
18:10 - Рабочий день завершен
18:15 - Пользователь начинает печатать
18:15 - Программа: "🚪 ОБНАРУЖЕНА АКТИВНОСТЬ ПОЛЬЗОВАТЕЛЯ"
18:15 - Программа завершается без блокировки/выключения
```

**Отслеживает:**
- 🖱️ Все движения мыши/тачпада
- ⌨️ Все нажатия клавиш

### 🔧 Отключение функции
```yaml
exit_on_activity_after_work: false
```

## ❓ Часто задаваемые вопросы

### 🎯 Общие вопросы

<details>
<summary><strong>Q: Программа обнаруживается как бот?</strong></summary>

**A:** Нет, программа использует:
- 🕐 Случайные интервалы между действиями
- 🖱️ Плавные движения мыши с кривыми ease-in-out
- ⏸️ Естественные паузы
- 📅 Реалистичное расписание с перерывами

Действия неотличимы от человеческих.
</details>

<details>
<summary><strong>Q: Как часто обновляется файл конфигурации?</strong></summary>

**A:** Разные файлы обновляются по-разному:
- **`config.yaml`** (основные настройки) — не обновляется автоматически, редактируется вручную
- **`activity_config_YYYYMMDD.json`** (ежедневное расписание) — создается один раз в день при первом запуске
</details>

<details>
<summary><strong>Q: Можно ли изменить настройки во время работы?</strong></summary>

**A:** Нет, настройки применяются только при запуске. Нужно:
1. Нажать `Ctrl+C` для остановки
2. Изменить основной файл `config.yaml` (для постоянных изменений) ИЛИ ежедневный `activity_config_YYYYMMDD.json` (для изменений на один день)
3. Запустить программу снова
</details>

### 🛡️ Безопасность

<details>
<summary><strong>Q: Безопасно ли хранить пароли в конфиге?</strong></summary>

**A:** Файл `config.yaml` хранит пароли в открытом виде. Используйте с осторожностью. Рекомендуется использовать только для незначительных паролей или отключить функцию.
</details>

<details>
<summary><strong>Q: Может ли программа навредить системе?</strong></summary>

**A:** Нет, программа только эмулирует нажатия клавиш и движения мыши. Но клики могут случайно активировать элементы интерфейса.
</details>

### ⚙️ Настройка

<details>
<summary><strong>Q: Как отключить клики мыши?</strong></summary>

**A:** Установите в `config.yaml`:
```yaml
use_mouse_click: false
action_weight_mouse_click: 0
```
</details>

<details>
<summary><strong>Q: Как сделать движения мыши более заметными?</strong></summary>

**A:** Увеличьте `"max_mouse_range"` до 100-150 пикселей.
</details>

<details>
<summary><strong>Q: Программа слишком активна, как снизить?</strong></summary>

**A:** Увеличьте параметры в `config.yaml`:
```yaml
min_idle_time: 60
max_action_interval: 40
```
</details>

<details>
<summary><strong>Q: Как включить работу круглосуточно?</strong></summary>

**A:** Установите в `config.yaml`:
```yaml
afterhours_mode: before_and_after
```
</details>

<details>
<summary><strong>Q: Почему в пятницу другое расписание?</strong></summary>

**A:** Программа автоматически определяет день недели. Для пятницы используется специальное расписание с более ранним окончанием работы.
</details>

<details>
<summary><strong>Q: Программа мешает работе, совершая действия во время моей активности</strong></summary>

**A:** С версии 11.0 программа ждет минимум 60 секунд после любой вашей активности. Если действие уже началось — оно прерывается при обнаружении вашей активности.
</details>

<details>
<summary><strong>Q: Как долго программа ждет после моей активности?</strong></summary>

**A:** Минимум 60 секунд после любого движения мыши, клика или нажатия клавиши. Это встроенная защита и не настраивается.
</details>

<details>
<summary><strong>Q: Что происходит, если я начну работать во время серии нажатий программы?</strong></summary>

**A:** Серия немедленно прерывается, программа переходит в режим ожидания 60 секунд.
</details>

## 📞 Поддержка

### 🔧 Логи для диагностики
При возникновении проблем приложите:
1. 📄 Файл `activity_log_*.txt`
2. ⚙️ Файл `config.yaml` (основные настройки)
3. 📋 Файл `activity_config_*.json` (ежедневное расписание)
4. 🐍 Версию Python: `python --version`
5. 💻 ОС и версию

### ⚠️ Известные ограничения
- ❌ Не работает через SSH без X11
- 🍎 macOS может потребовать разрешения Accessibility
- 🪟 Windows может потребовать запуск от администратора для выключения
