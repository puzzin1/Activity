ИСХОДНАЯ ПРОГРАММА (activity5.py)
# ОПИСАНИЕ:
Базовая программа для симуляции активности пользователя, предотвращающая
переход компьютера в спящий режим или показ статуса "отошел".
# ОСНОВНОЙ ФУНКЦИОНАЛ:
- Отслеживание активности пользователя (мышь, клавиатура)
- Симуляция действий при бездействии пользователя
- Типы действий: движение мыши, нажатие стрелок, Ctrl+Tab, клики мыши, Shift
- Логирование действий в файл
- Настройки в виде словаря CONFIG внутри кода
# ПРОБЛЕМЫ:
- Все настройки жестко прописаны в коде
- Нет расписания работы
- Работает круглосуточно без учета рабочего времени
- Веса действий зашиты в коде
- Нет автоматизации после перерывов

- Дополнительные перерывы: 40-80 мин общее время (включая обед)
- Внерабочий режим: всплески активности по 30-70 сек каждые 7-9 мин
