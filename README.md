# 🖥️ Программа Симуляции Активности

Автоматическая симуляция пользовательской активности для предотвращения перехода компьютера в спящий режим и отображения статуса "отошел" в корпоративных системах.

## ✨ Возможности

### 🎯 Основной функционал
- ✅ **Автоматическая симуляция активности** - движение мыши, нажатие клавиш
- ✅ **Умное расписание** - автоматическая генерация рабочего дня с перерывами
- ✅ **Специальное расписание для пятницы** - короткий рабочий день 🎉
- ✅ **Три режима работы** - рабочий, перерыв, внерабочий
- ✅ **Поддержка тачпада** - отслеживание активности как с мыши, так и с тачпада
- ✅ **Естественное поведение** - случайные интервалы и плавные движения

### 🔐 Безопасность и контроль
- ✅ **Всплывающее предупреждение** - возможность отменить выключение компьютера
- ✅ **Умное завершение** - выход из программы при активности после работы
- ✅ **Блокировка/выключение** - автоматическая блокировка или выключение ПК
- ✅ **Маскировка паролей** - безопасное хранение последовательностей клавиш

### 📊 Настройки и логирование
- ✅ **JSON конфигурация** - все настройки в отдельном файле
- ✅ **Подробное логирование** - запись всех действий в лог-файл
- ✅ **Гибкая настройка** - веса действий, интервалы, режимы работы
- ✅ **Кроссплатформенность** - Windows, macOS, Linux

## ⚙️ Конфигурация

### Файл конфигурации
Создается автоматически при первом запуске: `activity_config_YYYYMMDD.json`

### Основные параметры

#### 🎮 Параметры симуляции
```json
{
  "min_idle_time": 30,           // Мин. время бездействия (сек)
  "max_idle_time": 70,           // Макс. время бездействия (сек)
  "min_action_interval": 3,      // Мин. интервал между действиями (сек)
  "max_action_interval": 20,     // Макс. интервал между действиями (сек)
  "max_mouse_range": 50,         // Диапазон движения мыши (пикс)
  "natural_behavior": true       // Естественное поведение
}
```

#### 🎯 Типы действий и веса
```json
{
  "use_mouse_move": true,         // Движение мыши
  "use_keyboard": true,           // Нажатие стрелок
  "use_mouse_click": true,        // Клики мыши
  
  "action_weight_mouse_move": 3,  // Вес: движение мыши
  "action_weight_keyboard": 3,    // Вес: стрелки
  "action_weight_ctrl_tab": 1,    // Вес: Ctrl+Tab
  "action_weight_mouse_click": 2, // Вес: клики
  "action_weight_safe_key": 2     // Вес: безопасная клавиша (Shift)
}
```

**Веса** - чем больше вес, тем чаще действие будет выбрано.

#### ⏰ Расписание работы
```json
{
  "work_start_min": "08:45",     // Раннее начало работы
  "work_start_max": "09:05",     // Позднее начало работы
  "work_end_min": "18:00",       // Раннее окончание работы (Пн-Чт)
  "work_end_max": "18:20",       // Позднее окончание работы (Пн-Чт)
  
  "friday_work_end_min": "16:35", // Раннее окончание в ПЯТНИЦУ
  "friday_work_end_max": "16:55", // Позднее окончание в ПЯТНИЦУ
  
  "lunch_start_min": "12:00",    // Раннее начало обеда
  "lunch_end_max": "14:30",      // Позднее окончание обеда
  "lunch_duration_min": 20,      // Мин. длительность обеда (мин)
  "lunch_duration_max": 30,      // Макс. длительность обеда (мин)
  
  "total_break_min": 40,         // Мин. общее время перерывов (мин)
  "total_break_max": 80          // Макс. общее время перерывов (мин)
}
```

**Особенности:**
- 🎉 **Пятница** - автоматически определяется день недели
- ⏰ В пятницу рабочий день заканчивается раньше (16:35-16:55)
- 📅 В остальные дни используется обычное расписание (18:00-18:20)

#### 🌙 Внерабочий режим
```json
{
  "afterhours_mode": "before_and_after",  // Режим вне работы
  "afterhours_burst_duration_min": 30,    // Мин. длительность всплеска (сек)
  "afterhours_burst_duration_max": 70,    // Макс. длительность всплеска (сек)
  "afterhours_burst_interval_min": 7,     // Мин. интервал между всплесками (мин)
  "afterhours_burst_interval_max": 9      // Макс. интервал между всплесками (мин)
}
```

**Режимы `afterhours_mode`:**
- `"disabled"` - нет активности вне работы, автозавершение
- `"before_only"` - активность только до начала работы
- `"before_and_after"` - активность до и после работы

#### 🍽️ Действия после обеда
```json
{
  "after_lunch_action": true,                    // Включить ввод после обеда
  "after_lunch_sequence": "password{Tab}{Enter}", // Последовательность клавиш
  "after_lunch_delay": 5                          // Задержка после обеда (сек)
}
```

**Специальные клавиши:** `{Enter}`, `{Tab}`, `{Space}`

**Примеры последовательностей:**
- `"mypassword{Enter}"` - пароль и Enter
- `"login{Tab}password{Enter}"` - логин, Tab, пароль, Enter
- `"user{Tab}{Tab}pass{Enter}"` - user, два Tab, пароль, Enter

#### 🔌 Завершение работы
```json
{
  "lock_on_exit": true,              // Блокировка при завершении
  "shutdown_on_exit": false,         // Выключение при завершении
  "show_shutdown_warning": true,     // Показывать предупреждение
  "shutdown_warning_time": 30,       // Время до завершения (сек)
  "exit_on_activity_after_work": true // Выход при активности после работы
}
```

#### 📝 Логирование
```json
{
  "verbose_logging": true  // Подробное логирование в файл
}
```

## 🎭 Режимы работы

### 1️⃣ Рабочий режим
**Когда:** В рабочие часы (не на перерыве)

**Поведение:**
- Полная симуляция активности
- Все типы действий согласно весам
- Случайные интервалы между действиями
- Плавные движения мыши

**Действия:**
- Движение мыши в ограниченном диапазоне
- Нажатие клавиш-стрелок (прокрутка)
- Ctrl+Tab (переключение вкладок)
- Клики мыши (если включено)
- Безопасная клавиша Shift

### 2️⃣ Режим перерыва
**Когда:** Во время обеда или короткого перерыва

**Поведение:**
- Активность полностью приостановлена
- Имитация отсутствия пользователя
- После обеда: ввод последовательности клавиш (если настроено)

**Типы перерывов:**
- **Обед:** 20-30 минут в диапазоне 12:00-14:30
- **Короткие перерывы:** 3-8 минут каждый

### 3️⃣ Внерабочий режим
**Когда:** До начала или после окончания рабочего дня

**Поведение зависит от `afterhours_mode`:**

#### `"disabled"` - Отключен
- Нет активности
- Автоматическое завершение программы в конце дня
- Блокировка/выключение компьютера

#### `"before_only"` - Только до работы
- Всплески активности только утром до работы
- Автоматическое завершение в конце дня
- Блокировка/выключение компьютера

#### `"before_and_after"` - До и после работы
- Всплески активности утром и вечером
- Программа работает круглосуточно
- Легкие действия: движение мыши и Shift

**Всплески активности:**
- Длительность: 30-70 секунд
- Интервал: 7-9 минут
- Только легкие действия

## 🔔 Всплывающее предупреждение

### Когда показывается
При завершении рабочего дня (если `show_shutdown_warning: true`)

### Внешний вид
```
┌────────────────────────────────┐
│     ⚠️ ВНИМАНИЕ!                │
│                                 │
│  Рабочий день завершен.         │
│  Компьютер будет ЗАБЛОКИРОВАН   │
│  через 30 секунд.               │
│                                 │
│      [  Отменить  ]             │
└────────────────────────────────┘
```

### Действия пользователя
- **Нажать "Отменить"** - продолжить работу
- **Не нажимать** - автоматическое завершение через заданное время

### Настройка
```json
{
  "show_shutdown_warning": true,   // Включить предупреждение
  "shutdown_warning_time": 30      // Время до автозавершения (сек)
}
```

## 🚪 Умное завершение

### Обнаружение активности после работы
Если включено `exit_on_activity_after_work: true`:

**Программа отслеживает:**
- Движения мыши/тачпада
- Нажатия клавиш

**При обнаружении активности после окончания рабочего дня:**
1. Программа немедленно завершается
2. Компьютер НЕ блокируется и НЕ выключается
3. Выводится сообщение в консоль

**Сценарий использования:**
Вы решили продолжить работу после 18:00, начинаете печатать → программа автоматически завершается без блокировки компьютера.

### Отключение функции
```json
{
  "exit_on_activity_after_work": false
}
```

## 📊 Логирование

### Консоль
**Выводится:**
- ✅ Информация при запуске (настройки, расписание)
- ✅ Ошибки и предупреждения
- ✅ Сообщения о завершении

**НЕ выводится:**
- ❌ Рабочие события (движения, клики)
- ❌ Статистика действий
- ❌ DEBUG сообщения

### Лог-файл
**Имя:** `activity_log_YYYYMMDD_HHMMSS.txt`

**Содержание:**
- Полная информация о запуске
- Все настройки и расписание
- Каждое выполненное действие
- Начало/окончание симуляции
- Переходы между режимами
- Статистика каждые 5 минут
- Информация о завершении

**Уровни логирования:**
- `INFO` - обычные события
- `DEBUG` - детальная информация
- `WARNING` - предупреждения
- `ERROR` - ошибки

## ❓ FAQ

### Общие вопросы

**Q: Программа обнаруживается как бот?**  
A: Нет, программа использует естественные паузы, случайные интервалы и плавные движения. Действия неотличимы от человеческих.

**Q: Как часто обновляется файл конфигурации?**  
A: Один раз в день. При первом запуске дня создается новый файл с новым расписанием.

**Q: Можно ли изменить настройки во время работы?**  
A: Нет, нужно остановить программу (Ctrl+C), изменить JSON-файл, запустить снова.

**Q: Что делать, если программа не запускается?**  
A: Проверьте установку pynput: `pip install pynput`. Убедитесь, что у вас Python 3.6+.

### Безопасность

**Q: Безопасно ли хранить пароли в конфиге?**  
A: Файл конфигурации хранит пароли в открытом виде. Используйте с осторожностью. Рекомендуется использовать только для незначительных паролей или отключить функцию.

**Q: Может ли программа навредить системе?**  
A: Нет, программа только эмулирует нажатия клавиш и движения мыши. Но клики могут случайно активировать элементы интерфейса.

**Q: Можно ли отключить выключение компьютера?**  
A: Да, установите `"shutdown_on_exit": false` и `"lock_on_exit": false`.

### Настройка

**Q: Как отключить клики мыши?**  
A: Установите `"use_mouse_click": false` и `"action_weight_mouse_click": 0`.

**Q: Как сделать движения мыши более заметными?**  
A: Увеличьте `"max_mouse_range"` до 100-150 пикселей.

**Q: Программа слишком активна, как снизить?**  
A: Увеличьте `"min_idle_time"` до 60 и `"max_action_interval"` до 40.

**Q: Как включить работу круглосуточно?**  
A: Установите `"afterhours_mode": "before_and_after"`.

**Q: Как изменить время окончания работы в пятницу?**  
A: Измените параметры `"friday_work_end_min"` и `"friday_work_end_max"` в конфиге. По умолчанию: 16:35-16:55.

**Q: Почему в пятницу другое расписание?**  
A: Программа автоматически определяет день недели. Для пятницы используется специальное расписание с более ранним окончанием работы.

### Проблемы

**Q: Программа завершается сразу после обеда**  
A: Проверьте `"after_lunch_sequence"` - возможна ошибка в последовательности клавиш.

**Q: Не работает блокировка на Linux**  
A: Установите gnome-screensaver: `sudo apt install gnome-screensaver`

**Q: Окно предупреждения не появляется**  
A: Убедитесь что `"show_shutdown_warning": true`. Проверьте поддержку tkinter: `python -m tkinter`

**Q: Программа не видит активность тачпада**  
A: Тачпад поддерживается автоматически через pynput. Если не работает, попробуйте переустановить: `pip install --upgrade pynput`

**Q: Как запустить программу на Windows проще?**  
A: Используйте файл `activity.bat` - просто дважды кликните по нему.
